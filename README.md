# Chori

- A modern Kanban-style task management application built with React, TypeScript, and Tailwind CSS. Chori focuses on clean UI/UX, responsive layouts, and smooth drag-and-drop interactions.

## Features
-  Create and manage Kanban boards
-  Drag-and-drop task organization with DND Kit
-  Global state management using Zustand
-  Persistent state storage with Local Storage
-  Responsive and modern UI inspired by Trello UX/UI
-  Reusable component architecture
-  Type-safe development with TypeScript

## Tech Stack
-  JS Logic: React/TypeScript
-  Styling: Tailwind CSS
-  State Management: Zustand
-  Drag and Drop Functionality: DND Kit
